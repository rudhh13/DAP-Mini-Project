# Smart Reminder System

A modern web application that helps users manage reminders with an intuitive interface.

## Features

- Create reminders with title, description, date, time, priority, and category
- View upcoming reminders in a clean, organized list
- Filter reminders by priority and category
- Mark reminders as complete/incomplete
- Edit and delete existing reminders
- Real-time notifications for upcoming reminders
- Browser notifications for reminders (requires permission)
- Responsive design that works on desktop and mobile
- Data persistence using browser localStorage

## Technology Stack

- HTML5
- CSS3 with modern features (CSS variables, Flexbox, Grid)
- Vanilla JavaScript (ES6+)
- Font Awesome icons
- LocalStorage for data persistence

## How to Use

1. Simply open the `index.html` file in a web browser
2. Create new reminders using the form on the left
3. View, filter, and manage your reminders on the right
4. Receive notifications for upcoming reminders
